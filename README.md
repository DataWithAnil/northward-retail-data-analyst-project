# Northward Retail — Data Analyst Portfolio Project

Real-world data analyst project from the **Data with Anil** YouTube series
**"Become a Data Analyst — Real Project Series"**.

You join **Northward Retail**, a Canadian retail company with 5 regions, as their new data analyst.
Every episode starts with a real stakeholder request → you answer it with **SQL** → build a **Power BI** dashboard → tell the story.

## 📁 What's in this repo
| Folder | What it is |
|---|---|
| `sql/` | MySQL scripts to create and load the Northward Retail database |
| `csv_raw/` | Raw data, the way it arrives in a real company (with messy values) |
| `csv_clean/` | Cleaned data, ready for analysis and Power BI |

## 🚀 How to start
1. Install **MySQL** and **MySQL Workbench** (free)
2. Open the scripts in the `sql/` folder and run them in Workbench
3. Watch Episode 0 and follow along, episode by episode
